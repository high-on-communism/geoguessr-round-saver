How to save

  1. Choose a file above and allow editing.
  2. Open a completed GeoGuessr game summary.
  3. Click + Save to JSON beside a round.
  4. Import the updated file into map-making.app when ready.

The setup tab can be closed. If Chrome expires permission, return here and click Reconnect, then retry the round.

Recovery copy

The previous file contents are retained locally before each write. Download that copy if you need to undo the most recent addition.

Avoid editing this same file in another program while saving rounds. Duplicate panorama IDs are skipped. Existing tags and metadata are kept.
